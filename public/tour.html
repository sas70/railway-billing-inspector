These are real numbers from one of my Railway workspaces. I run several Railway accounts and a few on Vercel, so they're a slice of my hosting bill, not all of it. On a plan whose fee already covers this much usage, idle charges may not add to the invoice, but they use up what the fee includes.

What you get

Pick one to see it. Every screenshot is from the live demo, which runs on made-up data.

It checks what Railway actually charged each project over the last two full days. A project with nothing running that was still charged says so, with the cost per day and the reason: memory or CPU still held somewhere, network traffic, or a volume that bills every day until it's deleted.

Usage against what your plan includes, the projected bill, and where the money went, by each project's status and by resource. Switch to last period to compare, or open Cost history for what changed day by day.

Search every project's summary, README and code from an index kept on your machine. Topic search finds a project about the same subject even when your words never appear in it, and every result shows why it matched.

Railway names every project with two random words. Swap them for names that say what each app does, several at once, with suggestions from each app's code.

Every service across every workspace in one table, newest deploy first. Sort by cost, filter to what's online, and turn things off in bulk, each change reviewed first.

Projected cost, what's live, what crashed, and what's worth a look this week. Tabs load in the background and stay loaded until you press Refresh.

Nothing changes until you approve it

The dashboard starts read-only. When you do make a change, it goes through the same four steps every time.

Run it on your account

About five minutes. You need Node.js 20.9 or newer and a Railway account token.

Get the code

git clone https://github.com/sas70/railway-billing-inspector.git

Install

cd railway-billing-inspector && npm install

Add your token

cp .env.example .env.local

Create a token at railway.com/account/tokens (choose No workspace), then paste it after RAILWAY_TOKEN_MAIN= in .env.local.

Start it

npm run app

Then open http://127.0.0.1:3100. It only answers on your own machine.
